**FICHA TÉCNICA Y DICCIONARIO DE DATOS**
Las fuentes utilizadas para la recolección de los datos son la página oficial de la F1 y el github de Jolpica. Para construir la base de datos se anotan los años desde el 2000 hasta el 2026. Se destacan los equipos que obtuvieron el primer lugar y mencionando el nombre del piloto. Además, se presentan todos los equipos que participaron y el puntaje que obtuvieron. Por lo tanto, a través de estos datos se busca saber rápidamente los ganadores y por cuánto le ganaron a los demás equipos. Estos datos son fácilmente comparables y sencillos de procesar para el lector. Además, esto permite graficar la información de manera visual muy atractiva. 

**DICCIONARIO DE DATOS**
El año se refiere al resumen de la temporada, es decir, todas las carreras de ese período. 
Piloto ganador se refiere a la persona que manejaba el auto del equipo que logró el primer lugar. 
Equipo ganador es el que obtuvo el primer lugar. 
Puntaje son los datos numéricos que obtuvo el equipo ganador en la temporada, 
Luego se presentan las posición de todos los equipos durante ese año y el puntaje obtenido. 

**DOCUMENTACIÓN**
Para realizar la limpieza de datos, utilicé la información de la página oficial de F1 en donde aparecían los ganadores por año y sus nombres. Sin embargo, buscando profundizar la información, se agregaron todos los equipos de cada año con el puntaje que obtuvieron. Para hacer eso, no utilicé herramientas, ya que lo hice a mano.
